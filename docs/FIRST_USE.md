# 第一次使用与自助诊断

本指南区分设备本机配置与手机远程配置。先核对屏幕丝印、驱动和发布记录；同为 4.2 寸三色屏不代表驱动相同。构建通过不能替代首启、OTA 和物理显示验收。

## 路径一：仅在设备本机使用

1. 按 [快速开始](../README.md) 选择对应驱动包，核对该包的来源与校验值，以及当前实机验证范围。
2. 黑色上键唤醒，等待墨水屏刷新完成，再长按约 5 秒松开。连接屏幕上的 `J-Calendar` 热点，密码是设备显示的随机 12 位密码。
3. 打开 `http://192.168.4.1`，填写自己的主／备用网络与天气 Host、API Key、天气位置。热点密码与天气 Key 都不属于远程管理密码。
4. 保存本机配置后等待重启与联网校时，核对日期、课程、天气和第四页的实物结果。缺网时可能保留缓存；缓存不能证明刚刚获取了新数据。

无需部署远程服务即可继续使用。刷新期间等待，不反复按键。

## 路径二：启用手机远程配置

1. 按 [部署说明](DEPLOYMENT.md) 建立自己的 HTTPS 服务。检查环境变量完整性、实际云函数产物和 Blob 持久化；`/api/health` 只证明服务存活。
2. 用管理密码登录手机配置站。首次模板需改为本人课程、作息、日期和待办；先保存一次测试修改，再重新读取以核对持久化。
3. 在设备本机配置页填写自有服务域名、设备原文 Token 和公开根证书。服务器只保存 Token 哈希；管理密码、Token、热点密码各自有不同用途。
4. 手机“保存到云端”仅保存服务端配置，无法直接唤醒休眠设备。短按上键可同步配置；网页“重新检查”仅读取状态。
5. 核对云端配置与设备回报版本及时间，再核对实物。匹配版本和 ACK 都不能证明物理屏幕已经显示了新内容。
6. 在“设置”下载配置备份；备份与脱敏诊断用途不同。备份包含课程和待办内容，勿作为公开诊断材料发送。

## 待办编辑与草稿

每项“编辑”可改标题、截止日期和重要程度；“应用到草稿”后仍须“保存到云端”。应用保留原 ID、完成状态及其他字段，取消不改草稿。应用后按截止日、重要程度重新排序，并定位该项；设备显示前 6 条未完成事项。

未应用编辑须先应用或取消，才能切页、保存、核对云端版本、导入或退出。关闭／刷新网页有未保存提示；编辑字段沿用本机草稿记录恢复。登录过期和网络失败不会重置草稿基准；云端冲突沿用“核对云端新版本”流程，不能自动覆盖。

最多 30 条，含已完成事项。接近上限时逐项删除已完成事项；没有新增批量清理。浏览器存储不可用时仅保留当前页面内存，务必留在页面重新登录，不要关闭或刷新。

## 看懂状态与下一步

| 结果 | 下一步 |
| --- | --- |
| 模板待填写 | 替换模板并保存本人配置 |
| 修改还未保存到云端 | 应用或取消当前编辑，再保存 |
| 已保存，等待设备同步配置 | 短按设备上键，再重新检查 |
| 设备已连接，新配置尚未确认 | 查看同步记录的读取与确认结果 |
| 设备已确认配置 vN | 核对实物显示 |
| 暂未收到新的设备报告 | 手动唤醒检查；离线原因未知 |

“上次报告的预计联网”来自设备上一条运行摘要，不是配置生效时间。过去的预计时间显示待新报告确认；不作秒级准点承诺。旧固件未上报字段时显示未知，离线设备无法即时提供故障原因。

## 复制脱敏诊断

在网页“脱敏诊断摘要”复制或手工选中摘要。固定白名单只输出配置／回报版本、规范化时间、合法版本号、错误类别、上次页面、是否有本机草稿；驱动未上报即未知，物理显示保持未确认。

摘要不含姓名、课程、待办标题、邮箱、Wi-Fi、Token、密码、账号标签或唯一 ID，不复制完整状态或请求。未经用户授权不会自动发送摘要。

| 故障类别 | 一个具体检查动作 |
| --- | --- |
| wifi | 在设备本机页检查本人网络设置 |
| connect / time | 检查设备时间、服务 HTTPS 和公开根证书 |
| auth | 核对设备原文 Token 与服务器哈希用途；网页登录过期则重新登录 |
| service / data | 在自己的服务端检查实际部署产物与配置校验错误 |
| storage | 查看本地保存失败记录，保留配置备份 |
| config | 补齐设备的远程域名、Token 与根证书 |
| ack | 保留最近读取与确认记录，正常联网后重新检查 |
| 未知 | 保留最后报告时间并手动检查，不猜测网络原因 |

## 本轮验证边界

本轮网页验证使用隔离虚拟账号、假 API 和真实本地 Chromium，覆盖桌面和手机宽度。没有生产部署、设备刷机、真实账号操作或通知发送；实物显示、全新设备首启／OTA 和独立新用户试用仍须另外验收。

## 公开版能力

第四页固定为待办；天气位置采用城市 ID。公开版没有私有雷达、VPS 账号、学校坐标或自动采集配置。首用模板使用公开示例，需由使用者替换。
