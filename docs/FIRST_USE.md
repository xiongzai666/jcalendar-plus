# 首次使用与自助诊断

可先在设备本机配置网络和天气，再按需启用手机远程配置。开始前请核对 [屏幕型号](HARDWARE.md)、[刷机步骤](FLASHING.md) 和 [验证范围](RELEASE_ACCEPTANCE.md)。

## 方式一：在设备本机配置

1. 下载对应驱动包，核对来源提交和 SHA256，再按刷机指南安装。
2. 短按上键唤醒，等待刷新结束。双击上键，或长按约 5 秒后松开，打开配置热点。
3. 连接屏幕上的 `J-Calendar` 热点，输入设备显示的 12 位随机密码，访问 `http://192.168.4.1`。
4. 填写主／备用 Wi-Fi、天气 Host、API Key 和天气位置。热点密码、天气 Key 与远程管理密码用途不同。
5. 保存后等待设备重启、联网校时和刷新，核对日期、课程、天气与待办页。

无需部署远程服务即可使用本机功能。网络不可用时可能显示缓存，缓存时间可帮助判断数据是否过期。刷新期间请等待结束后再按键。

## 方式二：启用手机远程配置

1. 按 [部署指南](DEPLOYMENT.md) 建立自己的 HTTPS 服务，配置云函数和 Blob 存储。`/api/health` 只表示服务正在运行；还需验证登录、保存和重新读取。
2. 用管理密码登录配置网页，将示例课程、作息、日期和待办替换为自己的内容。保存一次修改，再重新读取，确认数据已持久化。
3. 在设备本机配置页填写服务域名、设备 Token 原文和可信根证书。服务器保存 Token 的哈希；设备填写原文。
4. 手机点击「保存到云端」后，等待设备下次联网；也可短按上键手动唤醒。网页「重新检查」只查询状态，不能唤醒休眠设备。
5. 核对云端版本、设备回报版本和时间，再查看屏幕。设备确认收到配置后，仍需人工核对显示结果。
6. 在「设置」中下载配置备份。备份包含课程和待办内容，请妥善保存，不要作为公开诊断材料发送。

## 编辑待办与恢复草稿

点击待办的「编辑」，可修改标题、截止日期和重要程度。「应用到草稿」后，还需「保存到云端」才会生效；「取消」不改变草稿。

编辑保留原 ID、完成状态和其他字段，应用后按截止日期、重要程度重新排序并定位该项。设备显示前 6 条未完成事项；总量上限为 30 条，包含已完成事项，接近上限时可逐项删除已完成事项。

当前编辑须先应用或取消，才能切页、保存、核对云端版本、导入或退出。关闭或刷新网页会提示未保存内容，编辑字段可从本机草稿恢复。登录过期和网络失败不会重置草稿基准；发生版本冲突时，按「核对云端新版本」流程处理。

浏览器存储不可用时，草稿只保留在当前页面内存中。请留在页面重新登录并保存，关闭或刷新会丢失内容。

## 看懂同步状态

| 网页结果 | 下一步 |
| --- | --- |
| 模板待填写 | 替换模板，保存自己的配置 |
| 修改还未保存到云端 | 应用或取消当前编辑，再保存 |
| 已保存，等待设备同步配置 | 等待联网，或短按上键唤醒，再查询状态 |
| 设备已连接，新配置尚未确认 | 查看同步记录中的读取与确认结果 |
| 设备已确认配置 vN | 核对屏幕显示 |
| 暂未收到新的设备报告 | 手动唤醒检查，离线原因尚不明确 |

「上次报告的预计联网」来自设备上一条运行摘要，不能当作配置生效时间。预计时间已过时，需要等待新报告确认；旧固件未上报的字段显示为未知。

## 复制脱敏诊断

在网页「脱敏诊断摘要」中复制内容，或手动选中摘要。它只包含配置与回报版本、规范化时间、合法固件版本号、错误类别、上次页面和是否有本机草稿。驱动未上报时显示未知；摘要不会自动确认屏幕显示。

摘要不含姓名、课程、待办标题、邮箱、Wi-Fi、Token、密码、账号标签或唯一 ID，也不会自动发送。

| 故障类别 | 检查方式 |
| --- | --- |
| `wifi` | 在本机配置页检查 Wi-Fi |
| `connect` / `time` | 检查设备时间、服务 HTTPS 和可信根证书 |
| `auth` | 核对设备 Token 原文与服务器哈希；网页登录过期时重新登录 |
| `service` / `data` | 在服务端检查实际部署包和配置校验错误 |
| `storage` | 查看本地保存失败记录，保留配置备份 |
| `config` | 补齐远程域名、Token 和根证书 |
| `ack` | 保留最近读取与确认记录，正常联网后重新查询 |
| 未知 | 保留最后报告时间，手动检查设备 |

## 公开版功能与验证范围

公开版第四页为待办，天气位置使用城市 ID；不包含私有雷达、VPS 账号、学校坐标或自动采集配置。首次模板中的示例内容需要自行替换。

Z15 已有清洁首配、正常 OTA、保留配置、离线及 OTA 中止恢复的实机记录。倒计时、升级缓存及本轮显示更新经过主机定向验证，此公开 rc.6 镜像尚未安装实机；其他屏型只有构建验证，独立新用户试用尚未进行。网页桌面与手机宽度测试使用隔离账号、模拟 API 和本地 Chromium。完整记录见 [构建与验收](RELEASE_ACCEPTANCE.md)。
