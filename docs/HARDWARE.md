# 硬件与接线

## 最低条件

- 经典 ESP32（如 ESP32-D0WD 系列）开发板，4 MB Flash，3.3 V GPIO。
- 4.2 寸、400 × 300 黑白红屏，控制器／批次和本项目驱动匹配。
- 带屏幕所需升压电路和 FPC 连接器的驱动板；裸屏不能仅用接线连 ESP32。
- 两个瞬时按键，USB 数据线；需要电池供电时选板子支持的单节锂电池与充电／保护方案。
- 外壳、绝缘与固定件按实际板子、USB 和双按键尺寸制作。

USB 转串口（如 CH340C）用于刷机，不是屏幕控制器。电池保护板也不等于电量采样或充电芯片。

## 默认接线

| 功能 | ESP32 GPIO |
| --- | --- |
| 屏幕 DIN / MOSI | 23 |
| 屏幕 SCLK | 18 |
| CS | 5 |
| DC | 17 |
| RST | 16 |
| BUSY | 4 |
| 黑色上键／唤醒键 | 14 → 按下接 GND |
| 橙色下键／切页键 | 12 → 按下接 GND |
| 指示灯 | 22，按板子极性并配限流 |
| 可选电池 ADC | 32，经分压，禁止直连电池正极 |

屏幕驱动板 VCC/GND 按其资料连接；当前参考硬件用 3.3 V，不保证所有转接板容忍相同电压。颜色仅供识别按键，接线以 GPIO 为准。`include/wiring.h` 是唯一接线入口。

GPIO12 是启动配置脚，不得在启动时被永久拉高；固件睡眠前释放它。GPIO14 负责深睡眠唤醒，下键在休眠时不能单独唤醒。保留的 I2C GPIO22 与 LED 冲突，若安装 RTC，先调整接线与 LED 设置；本版默认使用联网校时，RTC 不是必需。

## 屏幕型号确认

看屏背标签、FPC 标号、原驱动资料，不只看商品尺寸。源码 `include/GxEPD2_display_selection_new_style.h` 中的 `SI_DRIVER` 分支对应四种环境。Z15 的已知实机记录不能证明其他批次全部兼容；不要拿未知屏幕反复试不匹配的波形。

## 电池

参考成品使用单节标称 3.7 V、1800 mAh、604050 尺寸电池；这是参考，不是必选型号。确认充电板支持、电池极性、接插件与外壳空间。成品可由电池刷新，并不代表板上已接 GPIO32 电池分压。未安装采样时电压低读数不能用作剩余电量。

可选采样参考上游 [分压示意](../assets/img/battery_adc.png)，接入前实测 ADC 端最高电压、倍率和误差。不要让裸露焊点碰电池铝塑膜或磁铁；固定 FPC 和导线时避免拉扯。无焊接经验优先选已焊好、带插接端子的套件。
