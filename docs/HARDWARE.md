# 硬件与接线

## 硬件要求

- 经典 ESP32 开发板，如 ESP32-D0WD 系列，配备 4 MB Flash，GPIO 电平为 3.3 V。
- 4.2 寸、400 × 300 黑白红墨水屏，控制器和批次与所选驱动匹配。
- 屏幕驱动板，包含所需升压电路和 FPC 连接器；裸屏不能直接接到 ESP32。
- 两个瞬时按键和一根 USB 数据线。需要电池供电时，选用开发板支持的单节锂电池、充电及保护方案。
- 按开发板、USB 接口和双按键尺寸准备外壳、绝缘及固定件。

CH340C 等 USB 转串口芯片用于刷机，与屏幕控制器无关。电池保护、充电和电量采样也是不同功能，选板时需分别确认。

## 默认接线

| 功能 | ESP32 GPIO |
| --- | --- |
| 屏幕 DIN / MOSI | 23 |
| 屏幕 SCLK | 18 |
| CS | 5 |
| DC | 17 |
| RST | 16 |
| BUSY | 4 |
| 黑色上键／唤醒键 | 14，按下接 GND |
| 橙色下键／切页键 | 12，按下接 GND |
| 指示灯 | 22，按开发板极性连接并配限流 |
| 可选电池 ADC | 32，须经分压，禁止直连电池正极 |

接线定义以 [wiring.h](../include/wiring.h) 为准。按键颜色仅用于识别，实际以 GPIO 为准。屏幕驱动板的 VCC 和 GND 按厂商资料连接；当前参考硬件使用 3.3 V，其他转接板需单独确认供电电压。

- GPIO12 是启动配置脚，启动时不得永久拉高；固件会在睡眠前释放上拉。
- GPIO14 用于深睡眠唤醒，下键不能独立唤醒设备。
- 预留 I2C 使用的 GPIO22 与 LED 冲突。安装 RTC 前需调整接线及 LED 设置；默认联网校时无需 RTC。

## 确认屏幕型号

请查看屏背标签、FPC 标号和原驱动资料。商品标注的尺寸、颜色和分辨率不足以确定驱动。四种构建环境与 `SI_DRIVER` 的映射见 [驱动选择头文件](../include/GxEPD2_display_selection_new_style.h)。

Z15 已有实机记录，其他批次仍需核对兼容性。型号不明时先确认控制器，避免反复使用不匹配的驱动波形。

## 电池与电量采样

参考成品使用单节标称 3.7 V、1800 mAh、604050 尺寸电池，可按实际硬件另选。安装前核对充电板支持范围、电池极性、接插件和外壳空间。

设备能够使用电池刷新，不表示开发板已接 GPIO32 电池分压。未安装采样电路时，电压低读数不能用于判断剩余电量。可选采样需按开发板资料设计分压，接入前实测 ADC 端最高电压、倍率和误差。

焊点需绝缘，避免接触电池铝塑膜或磁铁；固定 FPC 和导线时避免拉扯。无焊接经验可优先选择已焊接、带插接端子的套件。同名或相似开发板的引脚和电池接法也可能不同，均以对应厂商资料为准。
