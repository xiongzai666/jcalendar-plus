# 故障排查

| 现象 | 先检查 |
| --- | --- |
| 下键不切页 | 是否睡眠／刷新中；上键唤醒后等刷新完成，30 秒内再按 |
| 热点页出现后找不到热点 | 等热点启动；确认密码来自本机当前屏幕；不要用旧固定密码 |
| 手机保存后屏幕未变 | 云端已保存与设备已应用是两步；手动唤醒并查看上报版本／时间 |
| 503 服务未配置 | 云函数环境变量 3 项秘密及有效 `PUBLIC_ORIGIN`；健康接口成功不代表安全配置完成 |
| 403 来源无效 | 配置实际 HTTPS 源，不带路径／末尾斜杠；检查站点域名迁移 |
| 授权失败 | 设备原文 Token 与云端 SHA256 是否成对；管理密码不能替代 Token |
| 证书／连接失败 | 主备 Wi-Fi、NTP、DNS、站点证书与根 PEM；不要禁用 TLS 校验 |
| 天气失败 | 和风天气 Host/API Key/权限、城市 ID；日志与缓存读取时间 |
| 日期显示课但课程不对 | 学校日期覆盖、是否独立作息、槽位与起止时间；用保存前核对 |
| 电压约 0.47 V | 确认是否安装 GPIO32 分压；有电池不代表有采样，低值不一定是电池电压 |
| 编译失败 | 正确平台／固定依赖、网络访问、磁盘空间；用当前 `platformio.ini` |
| OTA 失败 | 驱动是否匹配、应用是否超过 `0x1e0000`、上传的是否为 firmware.bin |

报告问题时提供固件版本、ESP32／屏幕型号、复现时间和步骤、去敏后的错误类别。勿发密码、Token、完整 NVS／Flash 或含热点密码的照片。
